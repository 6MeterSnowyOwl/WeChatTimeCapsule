微信时间胶囊
==============

版本：v0.3.1 RC7（Windows x64 Portable，未签名本地候选版）

本候选版仅用于本机验证。FFmpeg 对应构建与依赖源码尚未齐备，
LICENSE_DISTRIBUTION_CHECK=BLOCKED，PUBLIC_RELEASE_READY=NO，尚未批准对外分发。

用途与运行
----------
把自己明确选择的微信一对一聊天保存成普通 Markdown 文件和本地媒体。
完整解压 ZIP，启动并登录 Windows 微信，再运行“微信时间胶囊.exe”。
添加备份对象后使用界面中的保存与核对功能。不要直接在压缩包内运行。

Portable 表示软件本身无需安装。设置、索引、日志与必要缓存位于当前用户的
本地目录，默认聊天资料位于“文档\微信时间胶囊”，不会跟随 EXE 保存。

首次使用前请了解
--------------
读取历史聊天需要对当前账号的数据库和附件目录进行账号级清点；读取范围
并不只是屏幕上已打开的聊天。数据库解密密钥来自当前微信进程内存，必要的
本地缓存、密钥资料和保存的聊天资料均应视为私密数据。只在自己的账号上使用。
程序在本机处理聊天数据，不上传聊天记录，不发送微信消息，不修改微信数据库。
本软件不是腾讯或微信官方产品，与腾讯、微信不存在隶属或合作关系。
当前适用的腾讯中国大陆服务条款风险仍为 UNKNOWN；该状态不表示已确认许可
或已确认违反条款。

支持与已知限制
--------------
保存文字、图片、引用/回复、系统消息、联系人名片、位置以及本地可恢复的
MP4 视频；网页/公众号链接、文件和小程序卡片保留可读取的信息。
语音、动画表情、拍一拍、缺失附件和未识别结构可能以占位或部分支持表示。
不会继续抓取链接指向的网页、公众号文章或小程序内容。

历史验收样本记录了 181 条占位、5 条部分支持和 1439 处表示差异。
表示差异尚未全部解释，不能据此判定聊天损坏，也不能据此宣称已恢复全部附件。
这些是既有样本的聚合记录，不是 RC7 新增真实账号采集或新版本实机验收。

兼容性与权限
------------
WeChat 4.1.13.63、4.1.13.65 是历史已测试版本，本轮没有重新执行真实微信验收。
其他 4.x build 仍以启动时只读能力检查为准；不能据此声称所有 4.x 均已测试。
Windows 11 是开发机环境。Windows 10 和独立无 Python 干净机器验收仍未完成。
程序以当前用户权限运行，不要求管理员权限。RC7 未签名；Windows 可能显示
“未知发布者”，请保留正常 Windows 安全设置。
